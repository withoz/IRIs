## 미결정 5개 — Phase 0 종료 시 확정

1. **타깃 GPU 범위** — RTX 필수 vs 구형 GPU 폴백 지원
   → GI 아키텍처 전체가 갈립니다. 폴백을 지원하면 AMD Brixelizer GI 경로를 별도 유지해야 함. AI-00-002(GTX 1060)가 그대로 폴백 검증기가 됩니다
2. **1순위 호스트 앱** — SketchUp / 3ds Max / Revit
   → **SketchUp이 유력.** WyoungK에 2026, AI-00-002에 2016이 설치되어 있고 **Revit은 두 머신 모두 없습니다**(SketchUp용 Revit Importer 확장만 존재). 기술 스택도 갈립니다(.NET vs C++ vs Ruby). Phase 0-2의 4번 과제로 판단
3. **구축 경로 A / B / C** — 게임엔진 위 / 렌더 프레임워크 위 / 밑바닥부터
   → 자료집 1장 참조. 현재 권장은 B
4. **라이선스 정책** — 클로즈드 상용 vs 오픈소스
   → IfcOpenShell(LGPL-3.0) 사용 가능 여부가 여기서 결정됨. 클로즈드면 web-ifc 검토
5. **플랫폼** — Windows 전용 vs 크로스플랫폼
   → RHI 선택에 직결

## 다음 단계 — Phase 0 (WyoungK 기준)

RTX 5060 Ti가 있으므로 아래 전부 실행 가능합니다.

### 0-1. 개발 환경 구축 — 거의 완료

| 항목 | 상태 |
|---|---|
| Visual Studio 2022 / 2026 (Desktop development with C++) | ✅ 설치됨 |
| CMake + Ninja | ✅ VS 2026 번들 사용 (PATH 등록 또는 개발자 명령 프롬프트 경유) |
| **Vulkan SDK (LunarG)** | ❌ **남은 작업 — 이것만 하면 0-1 완료** |

> **CMake 버전 주의.** 번들 CMake는 4.2.3입니다. CMake 4.x는 `cmake_minimum_required(VERSION 3.5 미만)` 지원을 삭제했고 nvpro-samples와 일부 NVIDIA SDK가 아직 구버전 선언을 쓰고 있어 **configure 단계에서 그대로 실패할 수 있습니다.** 실패 시 `-DCMAKE_POLICY_VERSION_MINIMUM=3.5`로 우회하거나 CMake 3.31 계열을 별도 설치하십시오.

### 0-2. 기술 검증 4종

| 순서 | 대상 | 목적 | 실행 머신 |
|---|---|---|---|
| 1 | [vk_raytracing_tutorial_KHR](https://github.com/nvpro-samples/vk_raytracing_tutorial_KHR) 완주 | RT 파이프라인 체득 | WyoungK (Vulkan SDK 필요) |
| 2 | [RTXPT](https://github.com/NVIDIA-RTX/RTXPT) 샘플 빌드 → **자체 IFC 모델 하나 띄우기** | 가장 빠른 현실성 판단 | WyoungK (Vulkan SDK 필요) |
| 3 | [NRD-Sample](https://github.com/NVIDIA-RTX/NRD-Sample) 실행 | 디노이징 품질·비용 감각 | WyoungK (Vulkan SDK 필요) |
| 4 | SketchUp Ruby API로 지오메트리 덤프 | 라이브 링크 실현성 | **WyoungK (SketchUp 2026)** — Vulkan SDK 없이 **지금 즉시 가능** |

> **Phase 0의 산출물은 코드가 아니라 의사결정입니다.** 4종을 마치면 위 미결정 5개에 답할 수 있습니다.
> 4번은 블로커가 없으므로 Vulkan SDK 설치를 기다리는 동안 병렬로 진행하는 것이 맞습니다.

**4번 프로브는 작성 완료 — [tools/sketchup/](../tools/sketchup/) 참조.** SketchUp Ruby 콘솔에서
`load 'E:/IRIS/tools/sketchup/iris_probe.rb'` 후 `IRIS::Probe.run`. 실행 결과는
[tools/sketchup/README.md](../tools/sketchup/README.md)의 "측정 결과" 표에 기록합니다. **아직 미실행.**

- VR 90 fps = 11.1 ms, 눈당 약 5.5 ms

## 주의사항

- **CMake 4.x 호환성** — 위 0-1 참조. NVIDIA 샘플 빌드 시 첫 번째로 만날 벽입니다
- **업스케일러 전제조건** — 모션 벡터 + 깊이 버퍼 + 지터링된 카메라. 렌더러 설계 초기부터 파이프라인에 넣지 않으면 나중에 갈아엎게 됩니다
- **라이선스 전염성** — Blender/Cycles는 GPL이라 상용 클로즈드 제품에 통합 불가. IfcOpenShell은 LGPL-3.0(동적 링크 조건)
- **5060 Ti는 보급형** — 128비트 버스입니다. 레퍼런스 장비는 아니지만, 보급형에서 개발하면 성능 목표에 정직해집니다. Enscape이 시장을 가져간 이유가 정확히 그 지점입니다
- **제품의 해자는 렌더러가 아님** — 자료집 0장 참조. 렌더링 코어는 SDK 조립이지만, CAD 라이브 링크는 참고할 오픈소스가 거의 없습니다
