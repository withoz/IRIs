Enscape형 실시간 렌더러
구축 자료집

Enscape을 만든다고 하면 대부분 렌더링 엔진을 떠올립니다. 그런데 제품을 분해하면 렌더러는 네 개 축 중 하나에 불과하고, 오픈소스 자료의 밀도는 축마다 극단적으로 다릅니다. 이 문서는 그 밀도 차이를 기준으로 정리한 기술 지도입니다.

에셋 · 머티리얼 라이브러리

Poly Haven CC0퍼블릭 도메인 — 상업적 사용 자유, 출처 표기 불필요. 포토스캔 PBR 재질 8K 이상, HDRI 16K 이상. 라이선스
ambientCG CC0PBR 재질 2000종 이상 + HDRI

이 두 곳만으로 초기 재질 라이브러리 300~500종은 즉시 구성 가능합니다. 반면 아래 항목은 자체 구축이 필요하고, 여기서 제품 차별화가 갈립니다.

  • 식생(수목·관목·잔디) — LOD + 빌보드 + 바람 애니메이션. CC0 소스가 가장 부족한 영역
  • 인물 — 라이선스가 까다로움. 초기엔 컷아웃 빌보드로 시작 권장
  • 가구·집기 — 큐레이션 비용을 별도 예산으로 잡아야 하는 항목
  • IES 광원 프로파일 — 조명 제조사 무료 배포분 활용. 건축 실내 사실감에 결정적

재질 표준으로 MaterialX + OpenPBR를 중간 표현으로 두면, 호스트 앱 재질을 자체 셰이더로 매핑하는 계층이 깔끔해지고 나중에 V-Ray·Arnold 룩 매칭이 쉬워집니다.

단계별 로드맵

Phase 1과 Phase 2는 병행해야 합니다. 순차 진행하면 렌더러가 완성된 뒤에야 “Revit에서 안 열린다”를 발견하게 됩니다.

0
기술 검증1~2개월
  • vk_raytracing_tutorial_KHR 완주 → RT 파이프라인 체득
  • RTXPT 샘플을 그대로 빌드해 자체 IFC 모델 하나를 띄워보기 ← 가장 빠른 현실성 판단
  • NRD-Sample 실행 → 디노이징 품질·비용 감각 확보
  • Revit 플러그인 “Hello World” + Element 순회 → 지오메트리 덤프

Phase 0의 산출물은 코드가 아니라 의사결정입니다. 이 넷을 마치면 경로 A/B/C 중 무엇을 갈지 확신이 생깁니다.

1
렌더링 코어3~6개월
  • Donut 또는 Falcor 기반 프레임 골격
  • glTF·USD 로딩 → BVH 구축 → ReSTIR DI + SHaRC GI + NRD + Streamline
  • 카메라 지터 + 모션벡터 파이프라인 초기부터 확보
  • 톤매핑(ACES/AgX), 노출, 화이트밸런스, DOF, 블룸
  • 태양 위치(위도·경도·일시) + 물리 기반 하늘(Hosek-Wilkie 또는 Bruneton) + HDRI 환경광
2
BIM 파이프라인3~6개월 · Phase 1과 병행
  • IfcOpenShell 또는 web-ifc 코어로 IFC 임포트
  • Revit 라이브 링크 — 증분 동기화 · GUID 델타 추적 · 인스턴싱
  • 재질 매핑 계층: Revit Material → MaterialX/OpenPBR → 자체 셰이더
  • nv_cluster_lod_builder로 대형 모델 LOD 자동 생성
3
제품화6~12개월
  • 에셋 라이브러리 + 배치 도구 — 식생 · 가구 · 인물
  • 출력: 스틸 / 360 파노라마 / 동영상 / 독립 실행형 뷰어
  • OpenXR VR 모드
  • SketchUp · Rhino · ArchiCAD로 호스트 확장
  • 라이선싱 · 업데이트 · 크래시 리포팅 인프라
