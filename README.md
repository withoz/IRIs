## 현재 상태

기술 조사 단계. Phase 0(기술 검증) 진입 전이며, 아래 항목이 미결정입니다.

- 구축 경로 (게임엔진 / 렌더 프레임워크 / 밑바닥)
- 타깃 GPU 범위
- 1순위 호스트 앱 (SketchUp / 3ds Max / Revit)
- 라이선스 정책 (클로즈드 상용 / 오픈소스)
