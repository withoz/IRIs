## 현재 상태

기술 조사 완료, 코드 없음. **개발 환경은 Vulkan SDK 하나만 남았고**(VS 2022/2026 C++ · CMake · Ninja · Windows SDK 설치 확인), Phase 0(기술 검증) 착수 가능 상태입니다. 미결정 항목 5개가 남아 있습니다.
자세한 내용은 [docs/00-진행상황.md](docs/00-진행상황.md) 참조.
